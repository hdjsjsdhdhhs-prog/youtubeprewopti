| Q-016 | Доступность OpenAI API с хоста приложения | DECIDED (2026-10-01): провайдер vibecode.moe | Phase 3.5+, ADR-0007 | Решение владельца: прямой OpenAI API не нужен, используется vibecode.moe (`YTL_VIBECODE_API_KEY`, `YTL_AI_PROVIDER=vibecode`) через тот же адаптер с другим `base_url`; с этой машины отвечает. Адаптер OpenAI оставлен (выбор провайдера — конфиг). Историческая запись: тест адаптера по ошибке отправил запрос с фиктивным ключом `sk-test` на `api.openai.com` (openai 3.x ходит через `httpx2`, respx его не перехватывает; тесты исправлены на `httpx2.MockTransport` + `.invalid`). Ответ — `403 unsupported_country_region_territory` («Country, region, or territory not supported»), т. е. блокировка по региону исходящего адреса этой машины/её прокси, до проверки ключа. Ключ этого не изменит. Варианты: worker на хосте в поддерживаемом регионе; другой AI-провайдер за тем же протоколом (`AIProvider`). Обходить региональные ограничения OpenAI (VPN и т. п.) не предлагается — это нарушает условия использования. Ошибка распознаётся адаптером и показывается понятным текстом. |

## Зафиксированные риски
| Риск | Вероятность | Влияние | Митигирование |
|---|---|---|---|
| Квота YouTube ограничивает discovery | Высокая | Среднее | Quota ledger, кэш, растягивание на дни, запрос квоты |
| Правовые ограничения холодных рассылок | Средняя | Высокое | Ручной approve, opt-out, suppression list, audit; решение владельца по юрисдикциям |
| Бан Telegram-аккаунтов | Высокая (при MTProto-outreach) | Среднее | Q-001; лимиты, cooldown, автопауза |
| Рост стоимости AI | Средняя | Среднее | Бюджеты, pre-flight оценки, кэш, prefilter |
| Расхождение dev (Windows) / prod (Linux) | Средняя | Среднее | CI на Linux, pathlib, UTF-8, `lc_messages=C` |
| Нехватка ресурсов dev-машины (4 ГБ) | Средняя | Низкое/Среднее | Ограничение конкуррентности воркера, при необходимости — Vite |
